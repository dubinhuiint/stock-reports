本次更新的核心结论

维持不变的部分（4 项）：
  1. 估值框架——SOTP 主锚 + PEG + DCF，储能 20x / 逆变器 15x 的政策折价倍数。
  2. 压力档情景判断——美国业务收缩已是管理层的明确指引，不再是"待研究"。
  3. DCF 的 FCFF 起始值 60 亿——H1 经营现金流 37.35 亿与 v6.3 基准一致，未偏离。
  4. 出口退税 2027 归零是最可量化的利润冲击（机械口径 -41 亿税后）。
需要修正的部分（本次共 6 项）：
  1. 股价与行情快照全面刷新——89.33 → 80.75（-9.6%），52 周新低刷新至 78.00；PB 3.69 → 3.43，PE(TTM) 16.86 → 15.24。
  2. 估值分位重算——PB 3 年分位 8% → 7.3%，PE 3 年分位 53% → 40.8%；新增 5 年分位（PB 4.4% / PE 24.4%），避免单一窗口误导。
  3. 修正 v6.3 的 SOTP 口径不一致——v6.3 正文称"锁定后经营净利 92.5 亿"，但分部表实际只用了 86 亿（漏计套保收益 6.5 亿）。v6.4 统一为 94.3 亿并重新拆分，SOTP 中性由 79 元升至 86 元。
  4. 技术面由"极弱"改判为"底部背离"——MACD 柱 -5.61 → +1.11（金叉）、KDJ J -5.89 → +24.09、RSI6 14.79 → 42.19；对应技术面评分 34 → 46。
  5. 补入订单与 AIDC 进展——9/17 德国 be.storaged 1.6GWh、10/6 阿尔巴尼亚 130MWh、柬埔寨 215.6MWh 并网、芬兰 600MWh；1–9 月公开订单 23 个 / 超 33.26GWh；欧洲需求上调至 74GWh；SST 中标之江实验室、获东阳光 130MW 意向。对应成长性评分 68 → 70。
  6. 补入资金面新数据——主动偏股基金 287 只（较上期 -109 只）、持股比例 4.77%（-0.50pct）；融资余额 77.15 亿（9/14 为 80.16 亿）。

投资结论：估值进入"温和低估"，但政策尾部风险未出清

价格向下、价值横向——这是本次最核心的错位。现价 80.75 已低于中性中枢 86 元（折价 6.1%），连最悲观的外资目标价（高盛 114 元）都已高于现价 41%；PB 3 年分位 7.3%、5 年分位 4.4%，处于历史极低位。技术面同时出现 MACD 金叉 + KDJ/RSI 底部背离，是 8 月以来第一次"估值 + 技术"同向改善。
但三点压制未解除：① 14420 行政令细则（约 12 月下旬）未落地，"受覆盖外国实体"的认定范围仍是最大变量；② 出口退税 2027/1/1 归零将吞掉 2027E 净利的约 23%；③ 本框架 2026E 归母 104 亿比一致预期 134 亿低 22%，若 H2 实际落在本框架一侧，则 86 元的中枢也要下修。下行仍有空间：悲观情景 55 元（-32%）、DCF 悲观 34 元。
